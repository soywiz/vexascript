# Native sample sweep: standard-library and interface lowering

The non-browser C++ sample sweep exposed several backend gaps that were easy to miss when checking JavaScript output only. `WeakMap` construction accepted an iterable in the JavaScript backend but rejected it in C++; static class fields were emitted as raw C++ members even though the native class used lazy accessors; and numeric `toString(radix)` calls lost their radix argument. Binary-buffer samples also exercised `TextEncoder`, `Uint8Array` iteration, `Uint32Array`, and `instanceof` checks that needed native lowering.

The sweep also found two interoperability details. Ordinary `.txt` imports are a supported text-asset form and must be inlined without requiring `?text`. Imported TypeScript samples use numeric enum lookup and tuple destructuring; native emission therefore needs computed enum-member lowering and tuple element conversion before arithmetic. Interface delegation required direct native forwarding for delegated properties and methods, plus a direct class-to-interface pointer conversion when the class already implements the interface.

The delegated-state sample exposed a separate top-level delegated-variable path: the JavaScript backend could read and write `var total by box(0)`, while C++ emitted references to nonexistent variables. Top-level delegates now retain a native backing object and lower reads, assignments, compound assignments, and updates through its `value` property. Local delegated variables remain an explicit unsupported native case rather than being silently miscompiled.

The first investigation branch treated every large integer array literal as a signed 32-bit array. CRC32's lookup table disproved that assumption at the C++ narrowing boundary. The durable fix keeps large integer literal arrays in `double` storage for the generic array runtime while typed `Uint32Array` values use the dedicated binary-buffer object. Another dead end was adapting every class passed to an interface through a record adapter; that made a native class's methods dynamic and caused a runtime “value is not callable” failure. Static interface conversion now preserves the class pointer when the implementation is known.

The native smoke test now links and runs the deterministic native sample matrix, including the binary-buffer, CRC32, class-delegation, delegated-state, text-import, and TypeScript-import regressions. Samples that intentionally depend on browser APIs, JavaScript-only packages, unsupported Proxy/Reflect behavior, or platform-specific SDL services remain outside this deterministic native contract.

Self-hosting the native CLI found backend-only regressions that ordinary samples did not cover. Optional access to enum members must guard the enum before looking up its member array, typed destructuring fallbacks must treat an absent C++ string-array element as an empty string rather than relying on JavaScript `undefined`, and dynamic native array views need an explicit bounds check before converting an element. The native CLI now self-links successfully.
